cite-check

Academic Reference List Validator

How it works
  1. Parse — splits your list into individual entries and classifies each as journal article, book, book chapter, website, or other.
  2. Extract — pulls out authors, year, title, journal/publisher, DOI, URL, and ISBN.
  3. Look up — queries CrossRef (articles), OpenLibrary + Google Books (books), and OpenAlex (fallback). Probes URLs for reachability.
  4. Verify — scores each reference against what was found using weighted field matching (title 40%, author 30%, year 15%, journal 10%, pages 5%). Formats the canonical Chicago Author-Date citation.

URL checking is limited by browser security: most URLs show "unverifiable" rather than pass/fail because the browser cannot read responses from other origins. A network failure (DNS error) is reported as "not found."
